# Karim Ayada — Portfolio

A clean, responsive portfolio website built with HTML, CSS and JavaScript.  
Designed to be fast, minimal, and easy to navigate — for applications and personal projects.

## Live
- Website: https://karim-ayd.github.io/portfolio/

## Features
- Responsive single-page layout
- Dark/Light mode toggle (saved in localStorage)
- Smooth reveal animations on scroll
- CV download button (`cv.pdf`)
- Social preview (Open Graph) image support (`img/og.jpg`)

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
